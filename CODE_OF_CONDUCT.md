# Code of Conduct

We are committed to a welcoming, respectful, and harassment-free community.
Participants must use professional language, respect differing viewpoints, and
avoid personal attacks, discrimination, sexualized conduct, doxxing, and
unwanted contact.

Project maintainers may remove comments, close discussions, or restrict
participation when behavior violates this policy. Report concerns privately
through the security or maintainer contact described in `SECURITY.md`.
